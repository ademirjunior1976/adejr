# Portfólio estático — GitHub Pages

Conteúdo 100% estático (sem servidor), pronto para o repositório `adejr`.

## Como publicar

1. Copie os arquivos desta pasta (`index.html`, `profile.jpg`, `.nojekyll`) para a raiz do repositório https://github.com/ademirjunior1976/adejr
2. No GitHub: Settings > Pages > Source: **Deploy from a branch** > Branch: `main` / pasta `/ (root)`
3. O site fica em https://ademirjunior1976.github.io/adejr/

Para usar um domínio próprio, adicione um arquivo `CNAME` com o domínio na raiz.
